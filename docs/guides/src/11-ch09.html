Backup and safety

The books live in one SQLite file on this computer. A backup is a copy of that file. Restore is deliberately manual so that a live database is never swapped underneath the app.

In this chapterCreate a backup · Restore · When to back up · Safety rules · This computer only

9.1Create a backup

Open Admin → Backup and click Create backup. The app writes a timestamped copy, for example crown-books-2026-10-22T09-15-00-000Z.db, into the backup folder next to the database.

  1. Click Create backup.
  2. Confirm the new row in the list. It shows the file name, creation time and size.
  3. Copy that file to a different drive or a USB stick. A backup on the same laptop is not enough.

A backup is a complete copy, not a delta. Restore is done outside the app, with the app closed.

Close the app first Restoring while Crown Books is open can corrupt the database. Close the app completely, including any window in the taskbar, before replacing the file.

9.2Restore a backup

  1. Create a fresh backup of the current books, even if they are wrong. It is your safety net.
  2. Close Crown Books.
  3. Open the app data folder. On Windows this is usually %APPDATA%\crown-books.
  4. Rename the current crown-books.db to crown-books.before-restore.db.
  5. Copy the chosen backup from the backups folder into the app data folder.
  6. Rename the copy to crown-books.db.
  7. Open Crown Books and sign in. Check the dashboard, the trial balance and a recent invoice.

The backup folder is usually %APPDATA%\crown-books\backups. If your installation uses a different folder, ask your administrator before moving files.

9.3When to back up

When Why
Before the first real bill So you can return to an empty, known state.
Every day after posting The day’s work is the most expensive thing to lose.
Before a GST return Freeze the numbers you are about to file.
Before a restore or upgrade Keep a copy of the current state even if it is imperfect.
Every Friday, off the machine Protect against disk failure, theft or ransomware.
At month end A clean copy for the accountant.

9.4Safety rules

  • Do not edit the database with another program while Crown Books is open.
  • Do not copy the app folder to another computer. The install lock will refuse to run, and the data may not be the same.
  • Do not restore a backup over a live database. Close the app first.
  • Do not keep every backup on the same laptop. Use a second drive or a USB stick.

9.5This computer only

Crown Books is offline by design. There is no cloud sync, no remote login and no automatic off-site copy. That is a feature for privacy and a risk for disaster recovery. The backup routine is the disaster recovery plan.

The 3-2-1 rule, in plain language Keep 3 copies, on 2 different kinds of storage, with 1 copy off the computer. For a small shop, that can be the live database, a daily backup on the laptop, and a weekly copy on a USB drive kept elsewhere.
